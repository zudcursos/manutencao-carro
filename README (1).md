# Manutenção do carro

App simples pra acompanhar manutenções do carro por data e por km rodado (troca de correia, pneus, óleo, etc). Instalável como app no celular (PWA), com notificação ao abrir se algo estiver vencendo.

## Como usar

Acesse o link do GitHub Pages e adicione à tela de início do celular.

## Arquivos

- `index.html` — o app
- `manifest.json` — configuração do PWA
- `sw.js` — funcionamento offline
- `icon-192.png`, `icon-512.png` — ícone do app
